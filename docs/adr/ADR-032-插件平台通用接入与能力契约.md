# ADR-032：插件平台通用接入与能力契约

状态：Accepted（实现与实际验收结果分别记录，不以设计代替验收）。日期：2026-10-01。

## 目标与执行边界

首期支持独立仓库的 Python 3.12 local_native Processor。同机媒体 Buffer、上游 Observation、同步 DAG
和异步 enrichment 均通过 ProcessorPluginService 执行。PostgreSQL 是执行事实权威，Rust 负责媒体数据面，
插件不得导入 services、获取数据库凭据或自行调用其他插件。共享解码、跨机媒体、容器插件及 Source/Sink 不在首期。

## 声明、类型与兼容

Manifest v2 使用 edge.material.plugin/v2；config schema、输入输出 payload schema、资源和执行模式随 release
锁定。schema 禁止外部引用，注册、执行和结果入库逐级校验。Observation 追加 schema 身份；非模型算法明确
model_applicability=NOT_APPLICABLE，使用 processor_release_id，不虚构模型或置信度。
Process 明确区分 OBSERVED、NO_OBSERVATIONS 与错误；无检测计入覆盖，但不合成空 Observation。
v1 通过兼容层读取，旧 revision、摘要算法和 VLM outbox bytes 不改写。新图发布时固定具体 release/config/schema。

## 独立制品与信任

SDK wheel 提供 sensoryplex-plugin 工具、生命周期服务和独立项目模板。发现、摘要和 schema 解析不导入插件代码。
bundle 含锁定依赖、离线 wheelhouse、SDK、schema、SBOM，复用 ADR-030 安全解包及蓝绿机制。
外部制品必须有 Ed25519 分离式签名；签名覆盖规范化发布声明中的完整制品身份及摘要。管理员明确登记签名公钥。
API 不相信客户端 trust/authenticated 声明，独立验证签名和所有摘要。撤销签名者阻止新增导入与部署，保留已运行实例。
签名认证不代表提供强沙箱；仅批准的发布者可在受控开发环境安装原生插件。

## 通用异步链路

快路径事务登记 enrichment 与不可变 outbox，publisher 发到按目标节点、release 和配置绑定的受控 route。
consumer 竞争拉取且遵守已有内存/并发/重投预算，通过活跃插件 Process 执行；结果先经认证 API 暂存，
NATS 结果通知仅包含 task_id/result_digest。fuser 比对原始任务 bytes、版本、来源、时间与 schema，事务追加事实。
取消优先、迟到结果丢弃、重复结果幂等；全部补全终态后执行收敛为 succeeded 或 succeeded_with_partial_enrichment。
既有 VLM publisher/fuser/consumer 保留兼容入口，不迁移历史消息。

## 配置、索引与验收

schema 驱动配置默认值、null 与整数规范化；配置只含业务参数，禁止密钥、宿主路径和任意网络地址。
新结果通过声明的文本字段路径提取文本，送入既有文本编码与索引；未声明文本时显式不索引。
使用仓库外帧亮度测量和亮度阈值插件、真实授权视频，验收签名、安装、同步/异步、查询、Range 回看及蓝绿回滚。
健康、模拟结果与契约测试不构成媒体 Golden Path。证据写入 implementation-status 和 verification。
