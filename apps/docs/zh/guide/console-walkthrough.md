# 控制台全流程

Web 控制台是唯一的产品面。本页走一遍 上传 → 任务 → 素材 → 回看 的闭环，并说明每个界面在能力缺失时会
报告什么。

## 开始之前

```sh
./deploy/up.sh && ./deploy/up-events.sh     # 控制面 + 常驻事件链路
make demo-seed                              # 供登录页使用的演示账号
make task-worker-daemon                     # 宿主常驻工作器
```

开发环境可通过浏览器访问 `http://127.0.0.1:5173`。单机开发环境默认激活 Demo 快速登录，可直接点击一键进入工作台：

![登录工作台](/images/console/01-login.png)

## 界面清单

| 路由 | 界面 | 用途 |
| --- | --- | --- |
| `/assets` | 视频库 | 导入媒体、查看准入状态 |
| `/jobs` | 处理任务 | 关联已发布方案创建并启动任务，查看 DAG 阶段拓扑与甘特图 |
| `/materials` | 素材检索 | 查询切片、读取观测、回看原片，支持字面关键词与向量语义检索 |
| `/plugins` | 插件 | 插件配置版本、健康度门禁与双槽位蓝绿热部署 |
| `/nodes` | 节点 | 节点拓扑、硬件加速引擎探测（Metal/CUDA/CoreML）与资源负载 |
| `/pipelines` | 方案 | 编排方案草稿、DAG 模型算子绑定与版本发布 |
| `/users`、`/audit`、`/access` | 管理 | 账号与角色、操作审计轨迹全量留痕、作用域凭据 |

## 1. 导入媒体 —— `/assets`

用演示账号登录，进入 **视频库**，点「导入视频」。支持 `.mp4` 与 `.webm`。上传完成后该行状态是「待准入」
——文件存在且可寻址，但还没有跑过任何推理，也就不存在素材。控制台不会预先造一条素材记录来把货架填满。

![视频库管理](/images/console/02-assets.png)

## 2. 创建并启动任务 —— `/jobs`

进入 **处理任务**，新建任务，把上传的视频与一个**已发布**方案关联（内置 OCR+Timeline 方案适合作为第一个），
然后点「开始处理」。

![处理任务队列](/images/console/03-jobs.png)

点击列表项的「执行详情」，可调出 DAG 阶段拓扑与甘特执行时序弹窗：
- **阶段拓扑泳道流**：清晰区分数据面输入、L1 判别快路径（OCR/ASR）、时间轴融合及 L2 延迟补全慢路径（VLM）；
- **全景执行甘特图**：以毫秒精度直观展示各模态处理算子的起止时间与真实执行耗时。

![DAG执行阶段拓扑泳道](/images/console/03-job-detail-topo.png)

![全景甘特执行时序图](/images/console/03-job-detail-modal.png)

任务只有在下列条件都成立时才可分发：

- 方案存在已发布、不可变的 revision；
- 目标节点在线且已通过预检；
- 节点满足方案的 placement 与数据本地性约束。

任一条不成立时控制台会显示具体未满足的前置条件。节点缺失按“节点离线”（HTTP 503 语义）上报，
而不是排一个永远静默等待的队列。

## 3. 让宿主工作器干活

```sh
make task-worker-status     # 常驻工作器还活着吗
```

宿主工作器保持同机 `local-host` 节点的心跳，消费任务执行意图，用 GStreamer 解码，
提取多模态文字与语音观测，把观测融合到时间轴，事务性追加入库，最后把任务标记 `completed` 或 `ready_for_review`。
正是这个完成动作触发向量化，并让该素材的检索面就绪。

## 4. 读取结果 —— `/materials`

当该行变成「查看素材」后，素材检索界面提供：

- **SENSORYPLEX HUD 仪表盘** —— 左侧 Timecode 与覆盖范围监控，中间 HTTP Range 原片视频播放器（支持游标精准步进与定位同步），右侧与底部联动展示 OCR 画面文字提取、ASR 语音转写对齐以及 VLM 场景画面描述；底部呈现具备毫秒精度的多轨时间轴总线（Timeline Bus）；
- **1 秒网格连续切片** —— 每一行是源 stream 的一个 `[start_ms, end_ms)` 窗口，挂着它的真实观测，无观测时标明待补充状态，拒绝虚构数据；
- **关键词与语义模式双模检索** —— 支持按字面子串过滤，或切换至「语义检索」输入自然语言描述（如“红长矢器”），常驻 BGE 嵌入与 Milvus Lite 向量引擎即时返回相似度距离与排序；
- **原片精准回看** —— 点击任一命中切片或观测，视频播放器秒级跳转至对应毫秒锚点进行原片切片流式回放。

## 5. 算力节点与插件管理 —— `/nodes` & `/plugins`

- **节点拓扑看板 (`/nodes`)**：实时监控各计算节点的 CPU 与统一内存负载、硬件加速引擎（Apple Silicon Metal / CoreML / NVIDIA CUDA）探测结果与共享内存（LeaseBuffer）零拷贝数据模式；
- **插件热部署 (`/plugins`)**：遵循 ADR-030，支持首方自研 Python 原生插件的独立进程双槽位蓝绿热部署，通过身份/摘要核对、参数校验及连续健康度门禁保障无感平滑切换。

![计算节点拓扑与加速引擎](/images/console/07-nodes.png)

![插件版本化双槽位蓝绿热部署](/images/console/06-plugins-hotdeploy.png)

## 哪些是刻意报告为不可用的

- 索引进程未启动前的语义检索。
- 本平台缺失后端的能力——原因来自 `unavailable_reason` 原文渲染，不会被换成一句通用话术。
- 管理界面里尚未接线的媒体准入与执行路径。底座不会把一个没实现的功能渲染成能用的样子。

## 验收

```sh
make golden-path-check
```

九个场景：鉴权、节点就绪、视频上传、方案发布、任务分发、端侧计算、向量落库、语义检索、原片回看。
这个检查没有在真实媒体上成功跑过之前，不要描述该闭环已完成——见
[能力实现状态](/zh/reference/status)。
